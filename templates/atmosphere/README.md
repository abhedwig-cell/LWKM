# Atmosferische CO2-basis

`atmospheric_1975-2020.co2` is byte voor byte overgenomen uit `root.zip`, `root/Ab/met/atmospheric_1975-2020.co2`, op 30 oktober 2026.

De werkelijke dekking is 1970 t/m 2025. Ieder jaar heeft de vaste waarde 360,80 ppm; de bronheader vermeldt referentiejaar 1995. De naam is historisch en blijft behouden voor consistente verwijzingen. Dit bestand is geen historisch variërende CO2-reeks.

Elke HRU krijgt bij generatie een eigen kopie naast de SWP en cropfiles. De cropfile verwijst lokaal via `ATMOFIL = 'atmospheric_1975-2020'`.
