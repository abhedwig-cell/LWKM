## Producers already isolated

BBC
- QBOT2: derived from paired MODFLOW heads and c1; equal selected MODFLOW-cell mean.
- membership: donor-equal semantics for modern producer; supplied source-current inversion retained only as provenance fixture.
- status: reconstructed; realized executable reconciliation strong, residual provenance mismatch remains.

DRA
- DRARES: derived from full-cell MODFLOW conductances; all-member by intentional model design.
- INFRES: conductance * infiltration-factor equivalent resistance.
- ZBOTDR: conductance-weighted drainage depth below local ground.
- LEVEL summer/winter: conductance-weighted local water-level depth, clamped.
- L: current source uses 4*dqsat_maj if system has length, otherwise 100.
- status: formulas reconstructed; full realized gate pending runtime access to newly supplied glk/dqsat rasters.

MET
- RAIN: selected-uopp weighted daily meteo raster.
- ETref: selected-uopp weighted daily meteo raster.
- RAD/Tmin/Tmax/HUM/WIND: direct daily lookup from meteo_maj district.
- WET: district lookup plus rain-duration consistency policy.
- meteo_maj: all-member category majority.
- status: district and WET realized-validated; RAIN/ETref realized gate pending same-period oracle.

## Static HRU attributes in current source

Land use / crop routing
- lgn_maj: CATEGORY_MAJORITY over all members.
- swetr: DERIVED from lgn_maj threshold.
- isnatuur: DERIVED from lgn_maj.
- crop mapping: external lu2crop table / renderer path; audit separately.

Soil / profile
- soil2_maj: CATEGORY_MAJORITY.
- bfe_maj: CATEGORY_MAJORITY unless representative-SVAT mode overrides from HRU schema.
- number of horizons: lookup from bfe_maj via nuhor table.
- status: OPEN_AUDIT for representative override provenance.

Bottom-boundary class
- bbc_maj: CATEGORY_MAJORITY.
- swbbcfile/swinco: DERIVED from bbc_maj.
- status: OPEN_AUDIT because realized BBC executable differs from supplied source state.

Coordinates / elevation
- xc_avg,yc_avg: initially EQUAL_MEMBER_MEAN, later source code selects nearest member to average coordinate for representative row/col/x/y.
- glk_avg: EQUAL_MEMBER_MEAN.
- hh_avg: EQUAL_MEMBER_MEAN.
- status: OPEN_AUDIT: determine which downstream outputs actually use each and whether support should be full-cell or uopp.

Areas
- area_sum: sum(uopp) over all members.
- areawb_sum: sum(uopp) over selected water-balance members.
- status: support semantics confirmed; selection provenance remains producer-specific.

Rooting / hydrology
- rds_maj: historical aggregation/representative override requires audit.
- dqsat_maj: aggregation used by DRA L=4*dqsat_maj; requires exact source reconstruction.
- c1_avg: harmonic-style aggregation through mean(1/c1) then inverse; used for alternative mixed boundary path, not active QBOT2.
- infil_avg: source aggregation requires audit; influences SWALLO.
- irrigation switch: category/majority path requires audit.

SWP / renderer parameters
- many constants (crunoff_par, crunon_par, MaxPondDepth, tempCbotk, kwelmax, Xi_inf_par etc.) come from control/template rather than HRU aggregation.
- template {{}} substitution from Martin R pipeline must be replaced by typed fields and direct renderer.
- external content files such as .bbc/.dra/.met are produced separately and referenced, not regenerated by renderer.
