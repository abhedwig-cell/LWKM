## Voorbereiding

```bash
python -m pip install -r tools/requirements-lhm-hru-swap.txt pytest
python -m pytest -q tests
```

Benodigde bronnen: Datamodel_10242.xlsx, run_files(1).zip, Template.zip, csv.zip, LHM2SWAP.zip, SVAT_INFO(1).CSV, grensvlak_NHIWQ_v2_fill.asc, LHM433_H1_MVG_Q4.zip en LHM433_DRA_REMAINING_Q4.zip. Identiteiten staan in docs/evidence/2026-10-19/source-register.json. Het oude datamodel met 9830 HRU's wordt niet gebruikt.

Stel bronpaden expliciet in:


De SQLite is uitsluitend een uitvoerrepresentatie van het werkboek:


Leg het geretourneerde ingestierapport vast. De huidige bronnen moeten 22 werkbladen en 10.242 Runs opleveren. Optionele indexen op de joinvelden versnellen herhaalde contextopbouw; zij veranderen de wetenschap niet.

## Drainage en BBC

De volledige drainageopdracht, inclusief bronhashes, staat per W07 in het machineleesbare statusregister. De runner normaliseert Windows-ZIP-paden zonder de payloadbytes te veranderen. Hoofdletters in IDF-namen worden bij ontdekking correct behandeld. Gebruik een expliciete stage-start en stage-end; het geselecteerde interval bepaalt de reikwijdte van de kwalificatie.

Q4 bewijst alleen byte-integriteit. Controleer daarna bronuitzonderingen, conductantiebehoud, H1/PIPE-bescherming, stagevolgorde, SWAP-bereiken en hydrologische respons. Stop een niet-gekwalificeerde compressie niet in een admitted pakket.

Voor W08 qq zijn dagelijkse head1/head2/c1 nodig. Voor W08-GW-L1 zijn dagelijkse m3-volumes met uniforme tekens nodig:

```bash
python -m tools.groundwater_l1_boundary --cells "$CELLS" --membership "$MEMBERSHIP" --contract "$CONTRACT" --start "$START" --end "$END" --out "$OUT/gw.csv"
```

Het contractbestand bevat units=m3/calendar_day, positive=into_layer1, layer=1, components=[flf,lat,ghb,wel] en controleerbare evidence_refs. De CLI schrijft een audit met input- en outputhashes. Het handmatig opschrijven van zo'n contract bewijst de pakketsemantiek niet.
