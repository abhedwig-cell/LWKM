Alle opdrachten hieronder worden uitgevoerd vanuit de repositoryroot. Gebruik een nieuwe uitvoermap per kwalificatieversie. De voorbeeldvariabelen verwijzen naar werkelijke lokale bestanden die eerst volgens het bronregister moeten worden gematerialiseerd.

## Voorbereiding

```bash
python -m pip install -r tools/requirements-lhm-hru-swap.txt pytest
python -m pytest -q tests
```

Benodigde bronnen: Datamodel_10242.xlsx, run_files(1).zip, Template.zip, csv.zip, LHM2SWAP.zip, SVAT_INFO(1).CSV, grensvlak_NHIWQ_v2_fill.asc, LHM433_H1_MVG_Q4.zip en LHM433_DRA_REMAINING_Q4.zip. Identiteiten staan in docs/evidence/2026-10-19/source-register.json. Het oude datamodel met 9830 HRU's wordt niet gebruikt.

Stel bronpaden expliciet in:

```bash
DB=/absolute/work/datamodel.sqlite
TEMPLATE=/absolute/extracted/Template/wwl.swp
ORACLES=/absolute/extracted/run_files
OUT=/absolute/new-execution
SWAP=/absolute/SWAP_4.3.1/tools/SWAP/swap_431
RUNTIME_LIB=/absolute/runtime/lib
CSV=/absolute/csv.zip
LHM2SWAP=/absolute/LHM2SWAP.zip
SVAT_FULL=/absolute/SVAT_INFO.csv
```

De SQLite is uitsluitend een uitvoerrepresentatie van het werkboek:

```python
from tools.xlsx_datamodel import materialize_workbook
report = materialize_workbook('/absolute/Datamodel_10242.xlsx', '/absolute/work/datamodel.sqlite')
```

Leg het geretourneerde ingestierapport vast. De huidige bronnen moeten 22 werkbladen en 10.242 Runs opleveren. Optionele indexen op de joinvelden versnellen herhaalde contextopbouw; zij veranderen de wetenschap niet.

## SVAT en HRU

```bash
python -m tools.run_current_data_reconstruction --csv-zip "$CSV" --lhm2swap-zip "$LHM2SWAP" --base-svat "$SVAT_FULL" --out "$OUT/svat" --keep-staging
```

De oudere tabel in LHM2SWAP.zip heeft geen opp(m2). Gebruik daarom de afzonderlijk gehashte rijkere SVAT-basistabel. De mappingkolom heet svat_orig. Controleer 427.656 unieke leden, 10.242 HRU's en 10.242 representanten, plus de area- en donorstatistieken. Een geslaagde QA is nog geen herberekening van Piet's oorspronkelijke clustering.

## Drainage en BBC

De volledige drainageopdracht, inclusief bronhashes, staat per W07 in het machineleesbare statusregister. De runner normaliseert Windows-ZIP-paden zonder de payloadbytes te veranderen. Hoofdletters in IDF-namen worden bij ontdekking correct behandeld. Gebruik een expliciete stage-start en stage-end; het geselecteerde interval bepaalt de reikwijdte van de kwalificatie.

Q4 bewijst alleen byte-integriteit. Controleer daarna bronuitzonderingen, conductantiebehoud, H1/PIPE-bescherming, stagevolgorde, SWAP-bereiken en hydrologische respons. Stop een niet-gekwalificeerde compressie niet in een admitted pakket.

Voor W08 qq zijn dagelijkse head1/head2/c1 nodig. Voor W08-GW-L1 zijn dagelijkse m3-volumes met uniforme tekens nodig:

```bash
python -m tools.groundwater_l1_boundary --cells "$CELLS" --membership "$MEMBERSHIP" --contract "$CONTRACT" --start "$START" --end "$END" --out "$OUT/gw.csv"
```

Het contractbestand bevat units=m3/calendar_day, positive=into_layer1, layer=1, components=[flf,lat,ghb,wel] en controleerbare evidence_refs. De CLI schrijft een audit met input- en outputhashes. Het handmatig opschrijven van zo'n contract bewijst de pakketsemantiek niet.

## Genereren en regressie

```bash
python -m tools.build_modern_population --database "$DB" --template "$TEMPLATE" --output "$OUT/population" --oracles "$ORACLES"
python -m tools.qualify_49_runtime --database "$DB" --template "$TEMPLATE" --oracles "$ORACLES" --output "$OUT/runtime49" --executable "$SWAP" --library "$RUNTIME_LIB"
```

De eerste opdracht genereert SWP-kandidaten en behoudt alle verschillen met de 49 oracles. Hij genereert geen ontbrekende MET/BBC/DRA. De tweede opdracht voert elk historisch pakket ongewijzigd uit en voert daarnaast een moderne technische proef voor 1971 uit. Alleen in die proef wordt de eerste numerieke diagnosekolom uit BBC gebruikt. Die keuze is geen moderne BBC-authority.

De executable vereist libimf.so. In deze sessie is de Intel runtime via het pakket intel-cmplr-lib-rt beschikbaar gemaakt. Gebruik de vastgelegde binary- en runtimehashes. Leg bij een nieuwe installatie versie en shared-library-identiteiten opnieuw vast.

## Een kandidaat uitvoeren

```bash
python -m tools.execute_swap_candidate --executable "$SWAP" --source "$INPUT_DIR" --destination "$OUT/run" --library-path "$RUNTIME_LIB"
```

De doelmap mag niet bestaan. De runner kopieert alleen gedeclareerde modelbestandstypen naar een schone uitvoermap. Controleer execution.json, dagelijkse tijdsdekking, normale voltooiing, waarschuwingen, balans en fluxen. Dit is een onderzoeksrunner, geen productie-admissionprogramma. Controleer voor admitted productie iedere input met tools.file_qualification_gate.require_admitted en voer daarnaast alle toepasselijke W11-W14-gates uit.
